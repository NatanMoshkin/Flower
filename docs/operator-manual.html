167_01 Saad — Flower

Operator's manual

מדריך למפעיל

Everything you need to run the machine from the panel. If you are diagnosing a fault or changing settings, use the technician manual instead.

כל מה שצריך כדי להפעיל את המכונה מלוח ההפעלה. אם אתה מאתר תקלה או משנה הגדרות, השתמש במדריך הטכנאי במקום.

1 · What this machine does

1 · מה המכונה עושה

The robot places a plate in the fixture. The machine then clamps it, drives the separator pins out, presses the push pins home, and releases. That whole sequence is one cycle. The robot asks for each cycle; the machine runs it.

הרובוט מניח מגש במתקן. המכונה תופסת אותו, מוציאה את פיני ההפרדה, לוחצת את פיני הדחיפה, ומשחררת. כל הרצף הזה הוא מחזור אחד. הרובוט מבקש כל מחזור; המכונה מבצעת אותו.

Your job is to put the machine into a state where the robot is allowed to ask, and to deal with faults. You do not have to start each cycle by hand — though you can.

התפקיד שלך הוא להביא את המכונה למצב שבו הרובוט מורשה לבקש, ולטפל בתקלות. אינך צריך להתחיל כל מחזור ידנית — אך אתה יכול.

Why two buttons must be held

Stopping the machine and starting a cycle are both important, so they need a deliberate hold. A knock or a brushed sleeve cannot trigger them. The 1 second can be changed on the screen.

מדוע יש להחזיק שני לחצנים

עצירת המכונה והתחלת מחזור הן שתי פעולות חשובות, ולכן הן דורשות החזקה מכוונת. מכה מקרית או שרוול שנתקל אינם יכולים להפעיל אותן. אפשר לשנות את השנייה במסך.

3 · Starting production

3 · התחלת ייצור

  1. Switch the machine on. The screen shows NOT_HOMED — this means not ready. Nothing will move.
  2. Make sure the screen is in Automatic mode.
  3. The GREEN button light is blinking. That is the machine asking you to press it.
  4. Press GREEN. The pistons all pull back to their home position and the screen changes to IDLE.
  5. The green lamp is now on steadily. The machine is ready and the robot may start sending work.
  1. הדלק את המכונה. המסך מציג NOT_HOMED — כלומר לא מוכן. שום דבר לא יזוז.
  2. ודא שהמסך נמצא במצב אוטומטי.
  3. נורית הלחצן ירוק מהבהבת. זו המכונה מבקשת שתלחץ עליו.
  4. לחץ ירוק. כל הבוכנות חוזרות למקומן והמסך משתנה לIDLE.
  5. הנורית הירוקה דולקת כעת באור קבוע. המכונה מוכנה והרובוט יכול להתחיל לשלוח עבודה.
The machine will not move until you press GREEN

This is deliberate. After power-on, after any time in Manual, and after a STOP, the machine refuses to run — even if the robot asks — until a person has pressed START. That is what stops it moving unexpectedly when nobody is watching.

המכונה לא תזוז עד שתלחץ על הירוק

זה מכוון. לאחר הדלקה, לאחר כל שהות במצב ידני, ולאחר עצירה, המכונה מסרבת לפעול — גם אם הרובוט מבקש — עד שאדם לחץ על התחלה. זה מה שמונע ממנה לזוז באופן לא צפוי כשאף אחד לא מסתכל.

4 · Stopping

4 · עצירה

Hold the RED button for 1 second. Its light blinks while you hold it, so you can see the machine is counting. When it takes effect the screen goes back to NOT_HOMED and the green lamp goes out.

החזק את הלחצן אדום שנייה אחת. הנורית שלו מהבהבת בזמן ההחזקה, כך שאתה רואה שהמכונה מונה. כשהפעולה מתבצעת המסך חוזר לNOT_HOMED והנורית הירוקה נכבית.

This is not a fault — nothing is broken, the machine is simply not allowed to run any more. To start again, press GREEN.

זו אינה תקלה — שום דבר לא נשבר, פשוט אין יותר אישור למכונה לפעול. כדי להתחיל מחדש, לחץ ירוק.

STOP is not an emergency stop

A cycle already under way finishes its current movement. The pistons are air-driven and springs pull them back, so cutting power makes everything retract — but do not rely on the STOP button to protect hands. Use the machine's emergency stop for that.

עצירה אינה עצירת חירום

מחזור שכבר בעיצומו ישלים את התנועה הנוכחית. הבוכנות מונעות באוויר וקפיצים מחזירים אותן, כך שהפסקת חשמל גורמת להכל להתכנס — אך אין להסתמך על לחצן העצירה כדי להגן על הידיים. לשם כך יש להשתמש בעצירת החירום של המכונה.

6 · If the red lamp comes on

6 · אם הנורית האדומה נדלקת

The machine stopped because something did not reach where it was expected — usually a piston that did not travel, or a plate that never arrived. The screen shows a short message saying which step failed.

המכונה עצרה כי משהו לא הגיע ליעדו — בדרך כלל בוכנה שלא זזה, או מגש שלא הגיע. המסך מציג הודעה קצרה המציינת איזה שלב נכשל.

  1. Look at the message on the screen and write it down if this keeps happening.
  2. Look at the machine. Is something jammed, is a plate crooked, is air connected?
  3. If you can see nothing wrong: press ORANGE once. The machine pulls everything back to home and becomes ready again.
  4. If something is jammed, do not just reset. Switch the screen to Manual and free it by hand first — see the next section.
  1. הסתכל בהודעה שעל המסך ורשום אותה אם התקלה חוזרת.
  2. הסתכל על המכונה. האם משהו תקוע, האם מגש עקום, האם האוויר מחובר?
  3. אם אינך רואה בעיה: לחץ כתום פעם אחת. המכונה מחזירה את הכל למקום ושבה להיות מוכנה.
  4. אם משהו כן תקוע, אל תאפס סתם. העבר את המסך למצב ידני ושחרר אותו קודם ביד — ראה בסעיף הבא.
The robot may reset the fault before you do

The robot watches the machine and can clear a fault itself, so the red lamp sometimes goes out on its own after a second or two. That is normal. If the same fault keeps returning, stop the machine and investigate rather than letting it retry.

הרובוט עלול לאפס את התקלה לפניך

הרובוט עוקב אחר המכונה ויכול לאפס תקלה בעצמו, ולכן לעיתים הנורית האדומה נכבית מעצמה לאחר שנייה או שתיים. זה נורמלי. אם אותה תקלה חוזרת שוב ושוב, עצור את המכונה ובדוק במקום לתת לה לנסות שוב.

7 · Moving things by hand

7 · הזזת חלקים ביד

Switch the screen to Manual. Now the three buttons move pistons directly: each one moves its group out while you hold it, and the springs pull the group back when you let go.

העבר את המסך למצב ידני. כעת שלושת הלחצנים מזיזים בוכנות ישירות: כל אחד מוציא את הקבוצה שלו כל עוד אתה מחזיק, והקפיצים מחזירים אותה כשאתה משחרר.

  • RED — the two grippers
  • ORANGE — the three separator pins
  • GREEN — the three push pins
  • אדום — שתי התפסניות
  • כתום — שלושת פיני ההפרדה
  • ירוק — שלושת פיני הדחיפה
Manual mode only

The buttons do not move pistons while the machine is in Automatic — not even when it is faulted. That is on purpose: in Automatic the sequence owns the pistons, and two things driving the same piston is how equipment gets damaged. Switch to Manual, do the work, then switch back and press GREEN to get ready again.

מצב ידני בלבד

הלחצנים אינם מזיזים בוכנות כשהמכונה במצב אוטומטי — גם לא כשיש תקלה. זה מכוון: במצב אוטומטי הרצף הוא הבעלים של הבוכנות, ושני גורמים המפעילים אותה בוכנה הם הדרך שבה ציוד נהרס. עבור למצב ידני, בצע את העבודה, חזור למצב אוטומטי ולחץ ירוק כדי להתכונן שוב.

8 · Running a cycle yourself

8 · הרצת מחזור בעצמך

From IDLE (green lamp steady), hold ORANGE and GREEN together for 1 second. The machine runs exactly one cycle and returns to ready.

מIDLE (נורית ירוקה קבועה), החזק כתום וירוק יחד שנייה אחת. המכונה מבצעת מחזור אחד בדיוק וחוזרת למצב מוכן.

Press ORANGE first, then GREEN

Pressing GREEN first is read as a plain START, so the machine re-homes. What happens next depends on how long that takes: if it finishes quickly the cycle still runs afterwards, but if it is still homing when the hold completes, your request is lost and nothing runs. Release both and press again, orange first.

לחץ קודם על הכתום, אחר כך על הירוק

לחיצה על ירוק תחילה נקראת כהתחלה רגילה, ולכן המכונה מאפסת מקום. מה שקורה אחר כך תלוי בכמה זמן זה לוקח: אם זה מסתיים מהר המחזור עדיין ירוץ אחר כך, אך אם המכונה עדיין מאפסת מקום כשההחזקה מסתיימת, הבקשה שלך אובדת ושום דבר לא ירוץ. שחרר את שניהם ולחץ שוב, כתום קודם.

9 · Safety

9 · בטיחות

  • The pistons are held out by air and pulled back by springs. If power or air is lost, everything retracts. That is the safe direction, but it means a clamped plate is released.
  • The grippers and the pins can pinch. Keep hands clear whenever the green lamp is blinking, and whenever the robot is moving.
  • NOT_HOMED on the screen does not mean safe. It means not allowed to run. The robot can still be moving.
  • Only one gripper currently has air. The machine is set up to keep working on one, so do not assume both are holding.
  • הבוכנות מוחזקות בחוץ באוויר ומוחזרות בקפיצים. אם נופל מתח או אוויר, הכל מתכנס. זה הכיוון הבטוח, אך משמעותו שמגש שהיה תפוס משתחרר.
  • התפסניות והפינים יכולים ללחוץ ולפצוע. הרחק ידיים בכל זמן שהנורית הירוקה מהבהבת, ובכל זמן שהרובוט זז.
  • NOT_HOMED על המסך אינו אומר בטוח. הוא אומר אין אישור לפעול. הרובוט עדיין עשוי לזוז.
  • כרגע רק לתפסנית אחת יש אוויר. המכונה מוגדרת להמשיך לעבוד עם אחת, לכן אל תניח ששתיהן אוחזות.
Use the emergency stop for anything urgent

The RED button is a controlled stop that takes a second and lets the current movement finish. It is not a safety device.
