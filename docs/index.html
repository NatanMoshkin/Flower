What this project is. An assembly stand for pin-based bulb-flower components. One CP6606 Panel PC is the entire control system: it runs the TwinCAT PLC, the operator interface (classic PLC visualization, seven .TcVIS pages), and the robot comms. Eight pistons — 3 Sep, 3 Push, 2 Grip — are each a SOL-Spring two-position actuator (single Extend coil, mechanical spring returns it) driven by one instance of FB_SolSpringPiston_2Pos. FB_MasterAutoCycle runs a 15-state sequence over all eight, gated by two plate sensors. A single machine-wide bAutoMode is the sole source of truth for every piston's mode — there is no per-piston mode selection.

Robot comms are TCP-only, from the PLC itself. FB_RobotTcpClient (native ST on Tc2_TcpIp) dials the robot's server at 192.168.201.1:6001 and exchanges STATE:<n> / CMD:<m> frames plus the 11 tuning parameters. TF6310 is installed on the CP6606 — the documented exception to the avoid-paid-libraries rule. The former Python bridge (RobotBridge/) and the discrete-I/O handshake are both retired; so is the TwinCAT web HMI (Flower_PLC_HMI/, deleted 2026-07-26). The engineering-side UI is now FlowerPyHmi, a separate repo that talks ADS to the panel from a laptop.

How to open these docs:
Fastest (daily): double-click scripts\serve-docs.bat (or run scripts\serve-docs.ps1). It launches python -m http.server 8765 from the repo root and opens your default browser at http://127.0.0.1:8765/docs/index.html. Leave the terminal window open while browsing; Ctrl+C to stop.
Manual: cd C:\Users\Natan.Moshkin\source\repos\Flower && python -m http.server 8765, then browse to http://127.0.0.1:8765/docs/index.html.
Direct file:// open: works for the tabbed HTML pages, but the .md viewer needs HTTP (browsers block fetch() under file://) — the viewer will show a helpful error with the fix.
