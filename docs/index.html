Where the live source of truth is

היכן מקור האמת החי

CLAUDE.md in the repository root

The open-issues list, every architectural decision and its reasoning, and the record of what has and has not been verified all live there. It is maintained with the code, so it does not go stale the way a snapshot page does. The HTML here is generated from it and from the PLC source.

CLAUDE.md בשורש המאגר

רשימת הנושאים הפתוחים, כל החלטה ארכיטקטונית והנימוקים שלה, והתיעוד של מה אומת ומה לא — כולם נמצאים שם. הוא מתוחזק יחד עם הקוד, ולכן אינו מתיישן כמו דף תצלום. ה-HTML שכאן נוצר ממנו ומקוד ה-PLC.

Regenerate these pages with python scripts/manuals/build_manuals.py and python scripts/statediagram/build_state_diagrams.py. Edit the content modules under scripts/, never the generated HTML.
